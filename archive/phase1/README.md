# Archived Phase 1 Planning Documents & Spreadsheets

This directory contains historical Phase 1 planning materials for the Reliable Data Transport System Honours project:

- `Full_Soc_Address_Map.xlsx` / `.ods`: Early tentative memory map draft.
- `SoC_Honours_Phase1_Report.xlsx`: Phase 1 milestone planning matrix.
- `generate_phase1_excel.py`, `update_addresses.py`, `update_addresses_v2.py`: Address calculation scripts from Phase 1.

> [!NOTE]
> These materials are preserved for historical reference and record-keeping only.
> For the active synthesizable SoC register definitions, memory apertures, and MRAC attributes, consult the authoritative documentation at:
> `docs/address_map.md`
